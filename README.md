# Python Day 79 - User Input Sum and Average

This program takes multiple numbers from the user and calculates their sum and average.

## Example

Input:
10
20
30
40
50

Output:
Numbers: [10, 20, 30, 40, 50]
Sum: 150
Average: 30.0

## Concepts Used

- for loop
- range()
- input()
- int()
- append()
- sum()
- len()
- Average Calculation
